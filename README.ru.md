# Mine Piano

Клиентский мод-пианино Fabric для Minecraft 26.2 (Java 25) с настоящим движком SoundFont и передачей через Simple Voice Chat.

## Возможности

- Интерфейс пианино в реальном времени: клавиатура и мышь.
- Собственный минимальный SF2-семплер: моно 48 кГц, блоки по 20 мс.
- 10 пресетов инструментов.
- Необязательная передача другим игрокам через Simple Voice Chat.
- Настройки сохраняются в `config/mine-piano/config.json`.

## Требования

- Fabric Loader и Fabric API.
- [Simple Voice Chat](https://github.com/henkelmax/simple-voice-chat) 2.6.x необязателен. Он нужен только для передачи звука пианино другим игрокам; без него звук остаётся локальным.

## Установка

Скачайте jar со страницы [GitHub Releases](https://github.com/AmadoMuerte/mine-piano/releases) и поместите его в `.minecraft/mods`. Также установите Fabric API. Установите Simple Voice Chat 2.6.x, если хотите передавать звук пианино другим игрокам.

## Управление

По умолчанию пианино открывается клавишей `P` (категория `MISC`; клавиша `key.minepiano.open`).

| Действие | По умолчанию |
| --- | --- |
| Клавиши пианино | `A=C`, `W=C#`, `S=D`, `E=D#`, `D=E`, `F=F`, `T=F#`, `G=G`, `Y=G#`, `H=A`, `U=A#`, `J=B`, `K=C` (следующая октава) |
| Мышь | Нажмите для ноты; ведите курсор для глиссандо |
| Октава | `Z` ниже, `X` выше |
| Сустейн | `Space` |
| Закрыть | `Escape` (посылает note-off для всех активных нот) |

Раскладку клавиш пианино можно изменить в настройках. Она сохраняется в `config/mine-piano/config.json`.

## Звук

Mine Piano использует собственный минимальный SF2-семплер, а не звуки нотных блоков Minecraft: моно 48 кГц, блоки по 20 мс, пул голосов и 0 выделений памяти на блок. Типичная локальная задержка составляет около 35–55 мс. Через Simple Voice Chat кадры пианино объединяются с обработанным микрофоном и передаются как обычный голос игрока. Действуют обычные правила близости, расстояния, групп и серверной ретрансляции.

Ноты с клавиатуры и мыши используют один фиксированный внутренний уровень удара. MIDI velocity остаётся внутренним параметром API семплера.

## Сборка

```sh
direnv allow
./gradlew build
./gradlew test
./gradlew runClient
```

Nix flake предоставляет JDK 25 и p7zip. Используется Gradle wrapper 9.5.1. При первой сборке скачивается архив SoundFont. Автономная сборка:

```sh
./gradlew build -Psoundfont=/path/to/upright.sf2 -PgmSoundfont=/path/to/GeneralUser-GS.sf2
```

`downloadDevMods` скачивает Simple Voice Chat в `run/mods` для разработки.

## Ограничения

- Удалённые слушатели получают пианино через буфер джиттера Voice Chat, что добавляет ожидаемые 50–100 мс.
- Передача голоса требует работающего клиента Simple Voice Chat и потока микрофона. Она недоступна, когда голосовой чат отключён или нет доступного микрофона, запускающего этот поток.
- Звук пианино смешивается с реальным микрофоном и передаётся, даже если игрок выключил микрофон или не удерживает push-to-talk. Отключите «Transmit to Voice Chat» в настройках пианино для только локального воспроизведения.
- `javax.sound.sampled` может перейти на 44,1 кГц или вывод с синхронизацией по часам при отсутствии аудиоустройства.
- Встроенные инструменты отдают предпочтение умеренному размеру артефакта, а не детализации студийных библиотек.
